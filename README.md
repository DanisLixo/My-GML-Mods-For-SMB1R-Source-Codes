my epic mods for [Super Mario Bros. Remastered](https://github.com/JHDev2006/Super-Mario-Bros.-Remastered-Public)

## Mods Description

- **DawnLR-CharacterRandomizer** - randomize your characters and customize the way it randomizes, my first attempt to mod the game
- **DawnLR-Partner** - brings other custom character to follow you, honestly my favorite mod
- **DawnLR-MovesetPlus** - bigger moveset to apply to custom characters or whatever
- **Luigi-Luigi** - silly disclaimer change, it was supposed to be for a resource pack but idk if it's being worked on
- **SuperMario2004** - this uses an object called WorldEnviroment to make the game impossible to play as time passes
- **ResourcePackRandomizer** - randomize the active resource pack per level, activate the resource packs you want in the title screen (compared to characterrandomizer, this one is pretty bare bones)
- **AlwaysVisibleInvBlock** - Invisible blocks stay visible during normal gameplay
- **CharacterDebugging** - debug tools for character animation and hitbox tweaking, press F12
- **DawnLR-GameKillerObj** - adds a game killer object to the editor
- **DawnLR-PeterGriffinTransition** - transition for [my peter griffin custom character](https://gamebanana.com/mods/663022)

## Important Notes

- this is primarily a backup of my work, but feel free to see how I've been modding this game through out these past months
- **WARNING:** This repository does NOT contain my Gun Mod, that's a separate beast entirely, this repo only have my GML (Godot Mod Loader) mods!

## How to Use

1. Follow the wiki on [how to mod using GML](https://github.com/JHDev2006/Super-Mario-Bros.-Remastered-Public/wiki/Godot-Mod-Loader-Mods#creating-gml-mods).
2. Paste any mod to a `mods-unpacked` folder inside the Godot project (create the folder if not there)
